Key Formulas

Quick Reference
Area under a curve
A = ∫ab f(x) dx
Where:
• y = f(x)
• Limits are x=a to x=b
If x = g(y)
A = ∫cd g(y) dy
Area between two curves
A = ∫ab |f(x) - g(x)| dx
If x = g(y) and x = g(y)
A = ∫cd |g(y) - h(y)| dy
Where:
• y = f(x) [ upper curve ]
• y = g(x) [ lower curve ]
Total area when curve crosses x-axis
A = ∫ab |f(x)| dx
Standard Areas
1. Circle:
    x2 + y2 = r2

  Area:

    A = πr2
2. Ellipse:
    x2/a2 + y2/b2 = 1

  Area:

    A = πab
3. Parabola:
    y2 = 4ax

  Area:

    A = 8a2/3
