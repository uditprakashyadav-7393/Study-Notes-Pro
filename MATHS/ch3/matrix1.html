Matrices

Introduction & Types of Matrices

What is a Matrix?

A matrix is a rectangular arrangement of numbers in rows and columns.

  • Denoted by capital letters (A, B, C)
  • Elements are written in square brackets
  • Position is given by row and column

Order of a Matrix

Order = rows × columns

Example:

1 2 3
4 5 6

This is a 2 × 3 matrix.

Types of Matrices (with Examples)

Row Matrix

Only one row.

1 2 3 4

Column Matrix

Only one column.

1
2
3

Square Matrix

Rows = Columns.

1 2
3 4

Zero Matrix

All elements are zero.

0 0
0 0

Identity Matrix

Diagonal = 1, rest 0.

1 0
0 1

Diagonal Matrix

Non-diagonal elements are zero.

2 0
0 5

Scalar Matrix

Diagonal elements are equal.

3 0
0 3

Important Notes

  • Equal matrices have same order and elements.
  • Identity matrix acts like 1 in multiplication.
  • Square matrices are used in determinants.
