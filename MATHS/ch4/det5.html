Cramer's Rule

📘 Cramer's Rule

For a system AX = B of n linear equations in n unknowns, if |A| ≠ 0, then the system has a unique solution given by:

x = D₁/D,   y = D₂/D,   z = D₃/D

where D = |A|, and D₁, D₂, D₃ are determinants obtained by replacing the 1st, 2nd, 3rd column respectively with the constants column B.

For the system: a₁x + b₁y + c₁z = d₁  |  a₂x + b₂y + c₂z = d₂  |  a₃x + b₃y + c₃z = d₃

✏️ Solved Example — Cramer's Rule (2 Variables)
Solve: 2x + y = 5  and  x − 3y = −4
D

D = |2,1;1,−3| = (2)(−3) − (1)(1) = −6−1 = −7

D₁

Replace col 1 with [5, −4]: D₁ = |5,1;−4,−3| = (5)(−3)−(1)(−4) = −15+4 = −11

D₂

Replace col 2 with [5, −4]: D₂ = |2,5;1,−4| = (2)(−4)−(5)(1) = −8−5 = −13

x

x = D₁/D = −11/−7 = 11/7

y

y = D₂/D = −13/−7 = 13/7

✏️ Solved Example — Cramer's Rule (3 Variables)
Solve: x + y + z = 6,   2x − y + z = 3,   x + 2y − z = 2
D

Expand |1,1,1;2,−1,1;1,2,−1| = 1(1−2) − 1(−2−1) + 1(4+1) = −1+3+5 = 7

D₁

Replace col 1 with [6,3,2]: D₁ = 6(1−2) − 1(−3−2) + 1(6+2) = −6+5+8 = 7

D₂

Replace col 2 with [6,3,2]: D₂ = 1(−3−2) − 6(−2−1) + 1(4−3) = −5+18+1 = 14

D₃

Replace col 3 with [6,3,2]: D₃ = 1(−2−6) − 1(4−3) + 6(4+1) = −8−1+30 = 21

✓

x = 7/7 = 1,   y = 14/7 = 2,   z = 21/7 = 3

Area of a Triangle

If a triangle has vertices at (x₁, y₁), (x₂, y₂), and (x₃, y₃), its area can be found using a determinant.

📐 Area Formula
Area = (1/2) |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|
OR equivalently in determinant form:

Area = (1/2) · |det([[x₁, y₁, 1],[x₂, y₂, 1],[x₃, y₃, 1]])|
⚠️

The determinant can be negative depending on vertex ordering. We take the absolute value and then multiply by 1/2 to ensure area is positive.

✏️ Solved Example
Find area of triangle with vertices A(1,0), B(4,3), C(2,5)
1

Set up: Δ = (1/2)|det([[1,0,1],[4,3,1],[2,5,1]])|

2

Expand along R1: 1·|3,1;5,1| − 0·|4,1;2,1| + 1·|4,3;2,5|

3

= 1·(3−5) − 0 + 1·(20−6) = −2 + 14 = 12

4

Area = (1/2)|12| = 6 sq. units

3

Collinearity of Three Points

📘 Condition for Collinearity

Three points (x₁,y₁), (x₂,y₂), (x₃,y₃) are collinear (lie on the same line) if and only if:

det([[x₁,y₁,1],[x₂,y₂,1],[x₃,y₃,1]]) = 0

This is because if they're collinear, the triangle formed has zero area.

✏️ Solved Example
Check if (1,1), (3,3), (5,5) are collinear
1

det = 1(3−5) − 1(3−5) + 1(15−15) = 1(−2) − 1(−2) + 0 = −2+2 = 0

✓

Determinant = 0 → Points are collinear. (They all lie on y = x.)

Consistency of a System of Equations

For a system AX = B, the nature of solutions depends on the determinant of A:

✅

|A| ≠ 0 — Unique Solution

System is consistent with exactly one solution. Use Cramer's rule or find A⁻¹·B.

♾️

|A| = 0, (adj A)·B = O — Infinitely Many Solutions

System is consistent but has infinite solutions (dependent equations).

❌

|A| = 0, (adj A)·B ≠ O — No Solution

System is inconsistent. The equations are contradictory with no solution.

|A|(adj A)·BTypeSolutions
≠ 0anyConsistentUnique ✓
= 0= O (zero matrix)ConsistentInfinitely many
= 0≠ OInconsistentNo solution ✗
✏️ Example — Checking Consistency
x + y = 3,   2x + 2y = 7
1

A = [[1,1],[2,2]], |A| = 2−2 = 0

2

adj(A) = [[2,−1],[−2,1]]

3

(adj A)·B = [[2,−1],[−2,1]]·[3,7] = [6−7, −6+7] = [−1, 1] ≠ O

✗

Since |A| = 0 and (adj A)·B ≠ O → System is inconsistent (no solution)
